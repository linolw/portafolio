# LinoDev — Portafolio

Portafolio web personal de Leonardo Lino, Ingeniero de Software.

## Stack

- HTML5
- CSS3
- JavaScript
- Diseño responsive
- Tema oscuro / claro
- Despliegue preparado para Vercel

## Ejecutar localmente

No requiere instalación de dependencias. Abre `index.html` directamente o inicia un servidor local:

```bash
npx serve .
```

## Estructura

- `index.html` — contenido y estructura principal
- `styles.css` — diseño, responsive y temas
- `script.js` — navegación, tema e interacciones
- `favicon.svg` — identidad visual
